Step 1: Create a brand new, correctly linked Alpine container
We will give it a distinct name (myfirst-alpine-bash) so you don't have to deal with random hash IDs anymore. Run this from your 	/python folder:

## if we use --rm in below cmd then container would be deleted after task execution
docker run -d -it --name myfirst-alpine-bash -v "$(pwd)":/app alpine sh

step2: update alpine
docker exec myfirst-alpine-bash apk update

Step 3: Install Python 3 inside it
Now, tell your new container to download Python:


docker exec myfirst-alpine-bash apk add --no-cache python3
Step 4: Run your script
Now that the volume bridge is properly built, Python will find your script immediately:

docker exec myfirst-alpine-bash python3 /app/1.py > 1.py.log

Step 5: to run my all py scripts nd getting their logs in one file with script name

docker ps -a -size
